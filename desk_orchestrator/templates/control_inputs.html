Choosing the right input signal

If turning the wheel shows KEY_VOLUMEUP / KEY_VOLUMEDOWN in the developer console, choose Two keys with increase 115 and decrease 114. Choose Relative axis only when the device reports a relative-axis event, such as REL_WHEEL. Input signals are translated into the active task’s configured IR commands.

Verify signals without controlling hardware

Run this on the controller host, using the selected interface. Turn the dial and move the slider separately. This reads input for 20 seconds without grabbing the device or sending hardware commands.

.venv/bin/desk input-monitor --device /dev/input/by-id/YOUR_CONTROL_INTERFACE --seconds 20

The account needs permission to read that input. Type 1 is a key, type 2 a relative axis, and type 3 an absolute axis. Configure the reported code(s) above. For the stock GMMK Numpad slider, choose GMMK Numpad slider (raw HID). To inspect it without hardware commands, add --gmmk-slider to the monitor command and use the selected numpad’s keyboard path. QMK MIDI slider firmware needs a different adapter.
