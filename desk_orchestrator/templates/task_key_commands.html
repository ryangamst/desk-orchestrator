Add one shortcut or a sequence. Use + to combine keys, such as Win+R or Cmd+Space. Use Add step for keys to send afterward; add a delay if an app needs time to respond. Each step releases its keys before the next.

Key names and limits

Letters A–Z, digits 0–9, F1–F24, arrows, Enter, Escape, Tab, Space, Home, End, PageUp, PageDown, Insert, Delete, Backspace, PrintScreen, Pause, Menu, CapsLock, ScrollLock, NumLock and Numpad0–9 are supported. Use Ctrl, Shift, Alt / Option, Meta / Cmd / Win / Super; prefix Right for right-side modifiers.

Punctuation names: Minus, Equal, LeftBracket, RightBracket, Backslash, Semicolon, Quote, Backquote, Comma, Period and Slash. Use Shift+Equal for +. Shortcuts send physical keys using the connected computer’s keyboard layout; capital letters do not add Shift automatically. Advanced keyboard usages: 0x04–0xDF. Up to six keys plus modifiers per shortcut, 100 steps and 60 seconds of delays per sequence. {% if serial_keyboard %}Extended keys depend on the bridge firmware and connected computer.{% else %}F13–F24 and usages above 0x65 need the updated USB gadget setup.{% endif %}
